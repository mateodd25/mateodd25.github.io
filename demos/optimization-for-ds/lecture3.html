The model and the two mathematical guarantees

A concrete least-squares problem. Use the orthonormal basis

u₁ = (1, −1, 0) / √2,
u₂ = (1, 1, −2) / √6,
v = (1, 1, 1) / √3.

With two observations and three parameters, set

X = √2 [u₁ᵀ; u₂ᵀ / √κ],   y = √2 (1, 1 / √κ).

Thus the plotted objective is exactly

f(w) = ¼ ‖Xw − y‖²
= ½ [(a − 1)² + (b − 1)² / κ].

The solution set is {u₁ + u₂ + cv : c ∈ ℝ}. Its minimum-norm point is w† = u₁ + u₂, with norm √2. Changing κ changes X and y together, preserving this solution set.

Fast convergence without strong convexity. The loss is flat along v, but

½ ‖∇f(w)‖² = ½ [(a − 1)² + (b − 1)² / κ²]
≥ (1 / κ) f(w).

Hence μ = 1/κ and L = 1. For 0 < η ≤ 1/L, the usual PL theorem gives f(wt) ≤ (1 − ημ)tf(w₀). “Linear convergence” means geometric decay per iteration.

Implicit bias. The GD recurrence separates into three coordinates:

at = 1 + (1 − η)t(a₀ − 1),
bt = 1 + (1 − η/κ)t(b₀ − 1),
ct = c₀.

The first two coordinates converge to 1; the null-space coordinate never changes. Therefore w∞ = X†y + Πker Xw₀. Zero initialization selects the minimum Euclidean norm. A nonzero null component selects a different interpolator with identical training predictions.

The curves use the exact GD recurrence above. Thin, faint paths show the upcoming trajectory; solid paths show the iterations already taken. The PL bound is shown over the full horizon. Points below 10⁻⁸ are clipped to the plot floor, while exact zero has a separate row. A run that starts with zero loss has no normalized curve. Minimum norm is a statement among interpolators; it is not a general guarantee of better test error.
